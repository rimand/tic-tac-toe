# Tic Tac Toe

🎮 **Live:** https://tic-tac-toe-rho-green-66.vercel.app

A Tic Tac Toe web app with an unbeatable AI opponent and dark/light mode.

## Features

- **vs AI** — minimax algorithm with depth penalty (AI always plays optimally and prefers faster wins)
- **2 Players** — local multiplayer
- **Dark / Light mode** — persists to `localStorage`, syncs with OS preference on first visit
- **Scoreboard** — tracks wins for X, O, and draws across games

## Tech Stack

- Vite 6 · React 19 · TypeScript · Zustand 5

## Development

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```
